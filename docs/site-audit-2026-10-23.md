## 修复与优化

- 样式从约 50 个独立请求合并为 1 个压缩文件；公共交互脚本合并，搜索脚本按页面加载。
- 字体、图标、提示组件、搜索高亮库和性能采集库本地化，避免第三方 UI CDN 不可用时影响页面。
- 图标字体只保留站点使用的字符；字体和供应库以内容哈希更新缓存，样式与公共脚本使用构建版本，避免更新后沿用旧资源。
- 所有本地图片补充固有尺寸和异步解码，保留原图，生成较小的头像、论文和项目 WebP 预览；背景图按屏幕宽度选择版本。
- 修复搜索防抖尚未执行时点击清除，旧查询再次出现的问题；减少反复布局读取，限制高亮数量，并同步 URL、筛选数量和返回历史。
- 修复中文编码锚点和固定页头遮挡；锚点获得实际点击区域，保留正文排版。
- 图片预览使用原生模态对话框，支持 Enter、Space、Esc、点击关闭、焦点恢复；关闭后不再留下覆盖层。
- 移动导航支持实际按钮、展开状态、Esc、点击外部关闭及关闭事件；禁用 JavaScript 时仍能访问导航和全部成员。
- 深色模式兼容浏览器阻止本地存储的情况。补充键盘焦点、跳转主内容、状态播报及减少动态效果支持。
- 小幅调整文字和标签颜色以满足对比度检查，不改变整体布局。外部项目徽章不可用时显示可点击的文字后备。
- 修正 5 个返回 404 的 GitHub Stars 入口，链接到公开仓库；修正 StyIns 的 IJCAI 论文链接，并根据[官方论文](https://www.ijcai.org/Proceedings/2020/0526.pdf)纠正原先误填的作者列表。
- 404 搜索处理空白、特殊字符及正式域名，保留无 JavaScript 表单退化；404 加入 noindex，并从 sitemap 排除。
- 自动构建增加站内链接、锚点、元数据、图片、成员完整性、资源哈希、脚本语法和统计关键行为检查。
- 提交检查发现原有 `vendor` 忽略规则会误排除 `assets/vendor/`；已限定为根目录 `/vendor/`，并对暂存内容导出的干净目录进行构建，确保本地供应库实际包含在提交中。
