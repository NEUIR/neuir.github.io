# 论文搜索（2026-10-23）

搜索在本地浏览器内筛选页面上的全部 83 篇论文，保留原有论文排列和卡片布局。索引只建立一次，输入停止 150ms 后筛选；Enter 立即执行，Esc 或清除入口恢复全部论文。

## 查询规则

| 输入示例 | 行为与本次核验结果 |
| --- | --- |
| `辛海东`、`Haidong Xin`、`HaidongXin` | 均能找到对应作者的 3 篇论文；中文查询同时高亮页面中的英文作者名 |
| `辛海东 2026` | 同时满足作者和年份，3 篇 |
| `ACL 2026`、`ＡＣＬ　２０２６` | 大小写、全角字符及多余空白不影响匹配，13 篇 |
| `CCF A 2026`、`CCF-A 2026`、`CCF_A 2026` | 同时匹配等级和年份，17 篇 |
| `期刊`、`会议` | 分别显示 6、77 篇；也支持 `journal`、`conference` |
| `"retrieval-augmented" "2025"` | 所有引号短语都必须出现，短语内部保持连续；与普通关键词也按“同时满足”组合 |
| `A*-Thought`、`[RAG]` | 按字面文本匹配，不把用户输入当作正则表达式 |

索引包括标题、作者、会议/期刊、年份、CCF 标签、已有描述，以及可选的 `keywords`。中文姓名从 `_members/` 的中英文对照生成，只用于准确对应的作者；新增成员资料后，重新构建即可更新。未提供中文对照的合作作者使用英文名检索。

当前功能是文本筛选。中文主题词需要在论文 `keywords` 中维护，才会参与检索；不自动翻译标题或推测研究主题。可以在 `_data/citations.yaml` 中补充经确认的关键词，例如 `keywords: [检索增强生成, RAG]`。

## 操作与健壮性

- 中文输入法组合期间保留原输入和已有结果，选词完成后再筛选；组合期间 Enter/Esc 不抢占候选确认。
- 不在正常输入过程中重新赋值输入框，保留光标位置；查询最长 256 个字符，URL 直接传入的超长值也会限制长度。
- 空分类随筛选隐藏，零结果给出重试提示；清除后两类标题和全部论文立即恢复。
- 清除按钮、结果区清除链接均原地执行，取消待执行查询，恢复输入框焦点，保留其他 URL 参数和锚点。
- URL 使用 `replaceState`，便于复制检索地址，同时避免每次输入占用浏览历史；返回历史及页面缓存恢复时重新同步输入和结果。
- 有稳定的搜索区域标签、说明、结果播报和忙碌状态；禁用 JavaScript 时仍显示全部论文，并提示使用浏览器查找。
- 高亮限于可见结果，最多 100 处；高亮库不可用时仍可筛选。
- GA 只记录查询长度和结果数量，不发送原文；语义相同的重复 Enter 不重复统计；清除不产生额外浏览或导航事件。

输入法事件实现参考 [MDN compositionend](https://developer.mozilla.org/en-US/docs/Web/API/Element/compositionend_event) 和 [InputEvent.isComposing](https://developer.mozilla.org/en-US/docs/Web/API/InputEvent/isComposing)，同时保留独立组合状态及旧式键码兜底。

## 验证

- `npm test`：15 项全部通过。其中 8 项专门覆盖规范化、组合条件、引号短语、特殊字符、中文别名及高亮、输入法、清除竞态、历史恢复、超长查询和缺失高亮库；其余为统计及 404 测试。
- Chromium：上述实库查询、中文组合事件、原地清除、Enter/Esc、统计去重与本地不发送 Google 请求通过。
- 320、390、768、1024、1440px × 全部/中文筛选/零结果，共 15 组；另测 390、1440px 暗色筛选。无横向溢出，axe WCAG 2 A/AA、2.1 AA 与 best-practice 无违规。
- Safari 实际操作：中文作者 3/83、全角 CCF 组合 17/83、PVFH 1/83、新图放大/Esc/焦点恢复、结果区原地清除 83/83 通过。
- CPU 限速 4 倍，本地 83 篇论文上连续 10 次筛选（包括高亮及一次同步布局读取）实测 8.7–27.5ms。此为单次实验样本，不代表全部设备或真实用户百分位；150ms 防抖等待不包含在执行时间中。
- 生产构建和静态检查通过；全部论文有配图、搜索别名 JSON 有效、分类及总数一致。证据见 [检查数据](audit-2026-10-23/paper-search-followup.json)。
